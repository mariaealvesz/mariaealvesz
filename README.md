# Portfolio | Maria Eduarda Alves de Souza

Personal projects in business analysis and applied AI, to explore and practice ideas related to my work with data. All data is **fictional**, created only for demonstration. Nothing comes from work at any company.

## Projects

1. **KPI variation investigator**: compares the last two weeks of a metric, breaks down the change by segment (the contributions add up to the total change) and writes a summary. It also builds a structured prompt to use with an LLM.
2. **Segment-based message generator**: generates two A/B versions of a message by goal, segment, channel and tone, checks character limits and adds a pre-send checklist.

## How to run

Open `index.html` in a browser. No dependencies and no server.

## How it was built

- Plain HTML, CSS and JavaScript, with no external libraries.
- Logic tested on edge cases (invalid CSV, a single week, zero change, positive change).
- Built with the help of generative AI (Claude).
