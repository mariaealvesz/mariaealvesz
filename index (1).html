Projects

Small projects to explore and practice ideas related to my work with data and AI. They run in your browser and use fictional data created only for demonstration. Nothing here comes from my employer. They were built with the help of generative AI, and each one also builds a structured prompt, ready to paste into a model such as Claude or GPT.

1. KPI variation investigator

Problem: a metric dropped and the team asks why. The tool compares the last two weeks, shows how much each segment contributed to the change and writes a summary.

2. Segment-based message generator

Problem: build A/B variations of messages for each segment and channel while respecting length limits. The tool generates two versions, checks the limits and adds a checklist.

How they were built
  • Single page in plain HTML, CSS and JavaScript, with no external libraries and no data sent to any server.
  • Demo 1 breaks down the change in the weekly rate by segment: the contributions add up to the total change, which makes the summary verifiable.
  • Built with the help of generative AI (Claude), with the logic reviewed and tested.
  • Open source on my GitHub.
